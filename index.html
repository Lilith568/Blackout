What this tool guarantees

  • Nothing leaves your device. The page's security policy forbids every network request – you can verify this in your browser's developer tools.
  • Redactions are permanent. The output is rebuilt from pixels; redacted text, hidden layers, form fields and comments cannot be recovered.
  • Metadata is gone. Author, software, GPS location, timestamps and document IDs are not copied into the output.
  • It works with the cable unplugged. Save this page and use it on an air-gapped computer.
